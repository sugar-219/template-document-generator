# 模板文档批量生成软件 v1.15

本地交付包打开 `桌面版/模板文档批量生成.exe`，点击“载入示例”即可体验。复制或移动时请保留整个桌面版文件夹，`_internal` 是必需的运行依赖。GitHub 仓库只保留源码，不包含 EXE 和便携包；下载源码后请按下方步骤运行或构建。

v1.15 增加逐条完成进度保存。意外退出后，可载入原批次，校验并恢复已确认的结果；未确认的中间文件保留，继续或重试时避开已有文件名。大于 2,000 条记录的关键词搜索在后台进行，支持“停止搜索”，保留跨页选择和生成范围。主程序中的界面验证已分离到 `tools/smoke_test.py`，回归测试保存在 `tests/`。首次使用可先看 `快速开始.md`。

v1.14 采用纸白与墨绿的原生桌面界面，统一标题、按钮、输入框、绿色勾选与表格样式。统计摘要更紧凑，示例的 7 个字段可在普通窗口同时查看；检查错误与提示用不同颜色区分。结果页将分页合并到摘要行，优先把空间留给文档列表。小窗口自动收紧标题与间距，缩放后仍能操作。

导航选中标记与生成进度使用短暂平滑过渡，快速切换会取消旧动画并继续到新位置。右上角“界面动画”可随时开启或关闭，选择自动记忆。

支持 Word DOCX 模板、Excel / CSV 数据、字段映射记忆、数据检查及完整报告导出、刷新数据、最近文件、跨页选择、关键词搜索和原始行定位、文档预览、独立批次输出、停止后继续及失败重试。PDF 与真实页面预览需要已安装 Word 或 LibreOffice。

v1.13 为手动检查和生成前检查增加记录进度与“停止检查”。停止后不生成新文档、不显示未完成报告，已有批次保留；关闭窗口时在当前记录检查结束后停止。检查完成与停止同时发生时，也不会继续启动生成。

v1.12 优化大量重名时的编号查找，保持原有命名顺序；支持超过默认单字段长度限制的合法 CSV 长备注。历史批次载入后，在继续、重试和打包前再次核对文档、清单与保存状态，防止外部修改或另一窗口未保存的操作被静默接受。当前窗口状态保存失败时，仍可重试补存。

v1.11 增加字段“必填”、本批次 ZIP 导出和历史批次续作。“检查数据”与生成使用同一范围；必填空值阻止生成。正常完成、停止或关闭后，可在“生成结果”中载入原批次文件夹，按保存的模板与数据快照继续，源文件后续变动不影响原任务。ZIP 仅包含本批次文档与最新清单，不包含业务快照。

同时修复多行 CSV 分隔符识别、损坏引号检测、重名编号检查、重试文件冲突与 PDF 取消/进程退出竞争问题。多个窗口不能同时修改同一批次；过期状态必须重新载入。

源文件变动提醒和常用任务方案继续保留。源文件变化时暂停新批次及真实页面预览；“重新读取来源”保留匹配、必填与导出设置。任务方案保存来源路径、工作表、匹配、必填、命名和导出设置；载入时重新读取文件，范围重置为全部记录。方案不保存业务数据或记录选择，读取失败保留当前输入。

检查报告导出全部问题的源文件、工作表、原始行号和完整说明。修改匹配、命名或范围后须重新检查。数据改动后先保存，再刷新；已开始批次继续使用原来的数据。

## 文件

- `src`、`assets`、`requirements*.txt`、`tools`：源码、图标、依赖列表和构建工具。
- `示例文件`：原始通知模板及 Excel / CSV 示例。
- `快速开始.md`、`使用说明.md`、`界面预览.png`：快速试用、完整说明和界面。
- `tests`：核心流程、搜索及真实子进程中断恢复的回归测试。

测试代码保留在仓库；生成的测试文件与构建缓存位于已忽略的 `.build/`。桌面版及便携 ZIP 可按下方步骤在本机构建，软著材料单独在本地保存。详细操作与限制见使用说明。

## 开发和重建

使用 Windows 与 Python 3.13：

```powershell
python -m pip install -r requirements-dev.txt
python src/app.py
powershell -ExecutionPolicy Bypass -File tools/build.ps1
python tools/package_release.py
```

普通运行只需安装 requirements.txt。打包工具使用 PyInstaller；运行包已带所需依赖，无需安装 Python 或联网。

执行回归测试：

```powershell
python -m unittest discover -s tests -v
```

界面验证（需要桌面会话；使用独立测试设置与示例，不读取用户设置）：

```powershell
New-Item -ItemType Directory -Path .build -Force | Out-Null
python src/app.py --smoke-test .build/smoke.json --smoke-delivery --smoke-files --smoke-report --smoke-search
```

验证报告应为 `status: PASS`。增加 `--smoke-pdf --smoke-preview` 可验证 Word/LibreOffice 转换及页面预览。

历史续作依赖整个批次文件夹，包括 `.任务状态`、文档与清单。v1.15 在完成每条记录后保存进度；突然退出时，只恢复已成功写入并通过文件校验的记录。正在写入的文件不会自动视为成功，操作系统或磁盘未完成的写入也不保证恢复。详细限制见使用说明。
